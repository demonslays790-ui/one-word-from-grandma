A tiny deterministic program that writes one original word to `entry.txt`: the single word a grandma would text about AI — "Witchcraft", her verdict on a machine that talks back, remembers everything and does things she cannot explain. The word is 10 characters, and the program is stdlib-only with no network, clock, or randomness.

## Run it

```sh
python3 main.py
```
